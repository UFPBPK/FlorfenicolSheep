# FlorfenicolSheep

A PBPK Model for Florfenicol in Sheep

# \#This repository contains the PBPK and population PBPK model code used in our study.

The manuscript title is "An interactive Physiologically Based Pharmacokinetic (iPBPK) Model for Predicting Florfenicol and Florfenicol Amine Residues in Edible Tissues and Estimating Withdrawal Intervals in Market-Age Sheep".

The folder named "calibration and evaluation" contains a fit function for calibration and evaluation. The Excel files are raw data of the experimental PK studies.

The folder named "population PBPK code" contains the population PBPK model for sheep. The R code titled "MC\_Sheep\_FFC\_Figure4IM" is for florfenicol WDI prediction following two 20 mg/kg IM doses at 48-hour intervals in sheep. The R code titled "MC\_Sheep\_FFC\_Figure4SC" is for florfenicol WDI prediction following a single SC of 40 mg/kg in sheep.
